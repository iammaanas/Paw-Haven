# Paw Haven

A responsive animal welfare and rescue website concept.

## Run locally

Open \`index.html\` in a browser, or serve the repository with any static file server.

## Design system

The site follows Gecko Lab's typography pairing:
- Fraunces — display and editorial headings
- JetBrains Mono — labels, IDs and small metadata
- DM Sans — interface and body copy

Paw Haven has its own independent colour system:
- Pastel lavender \`#DCD6F7\`
- Blush pink \`#F8DDE5\`
- Sage green \`#DCEBDD\`
- Warm ivory \`#FFF9F0\`
- Soft beige \`#EADCCB\`
- Dark chocolate \`#493D38\`

## Demo boundaries

This is a static front-end concept. Animal profiles, campaign values and stories are illustrative. Browser forms use localStorage and do not contact an organisation. Payment checkout, verified payment webhooks, authentication, database-backed records, email delivery, file uploads to secure storage, live rescue map data and administrator workflows require backend services and are not represented as production-ready.

No payment is taken or marked successful by the demo.
